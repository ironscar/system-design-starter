# system-design-starter

- This workspace is to cover design docs for various system design problems.
- Each design problem will be its own folder.
- There may be up to 4 main files in each folder (along with any number of supporting files):
  - `1-initial-proposed-design`: the actual design solution presented initially
  - `2-peer-review-analysis`: the analysis of designs presented and reviewed among peers
  - `3-post-peer-review-design`: the design after taking feedback from peer reviews
  - `4-final-solution-analysis`: the analysis of actual industry solution compared to your latest design

1. URL Shortener: `./01-url-shortener`
