# System Design Starter

## Introduction

- This workspace is to cover design docs for various system design problems.
  - `./concepts` covers different system design concepts of note which are applicable to multiple problems
  - `./helpers` covers useful documentation for system design tradeoffs
  - `./interview-gaps.md` covers the current skill gaps with respect to current interview standards
- Each design problem will be its own folder.
- There will be an `attempts` folder with all the attempts named as `proposed-design-*` where `*` is the attempt number
  - each proposed design will have a `design.md` for the main design, a `review.md` for reviewing the design and a `diagrams` folder for any diagrams
- Additionally, each design may have supporting folders for other things
